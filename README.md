# Новогодний адвент — шаблон Telegram Mini App

7 коробочек (по умолчанию 23–29 декабря), каждая открывается в свой день.
Внутри пожелания, гифка, милая картинка, кассета с музыкой и предсказание,
а в последний день снежный шар с надписью «С Новым годом!».

Это чистый HTML/CSS/JS без сборки и без сервера: достаточно любого статического хостинга с HTTPS.

## Структура

```
index.html        — разметка
css/style.css     — оформление (цвета в :root)
js/config.js      — ВСЁ СОДЕРЖИМОЕ: даты, тексты, картинки, музыка
js/art.js         — SVG-графика крышек и встроенных иллюстраций
js/decor.js       — коробочка-заставка, ёлка и 10 шаблонов игрушек
js/app.js         — логика: заставка, даты, открытие, хранение, музыка, анимации
js/tree.js        — общая ёлка: выбор игрушки, подвешивание, синхронизация
assets/           — сюда кладите свои .gif / .png / .jpg / .mp3
```

## Как поменять содержимое

Откройте `js/config.js`:

- `startDate: '2026-12-23'` — день первой коробочки, каждая следующая открывается на день позже;
- в `days` для каждой коробочки задаются `type` (wish / gif / image / music / fortune / globe), тексты и `cover` (рисунок на крышке);
- свои файлы: положите их в `assets/` и укажите путь, например `src: 'assets/cat.gif'`.
  Если `src` пустой, показывается встроенная анимация или иллюстрация, а для музыки играет «Jingle Bells», синтезированная прямо в браузере.

Коробочек может быть сколько угодно: добавьте объекты в `days`.

## Проверка локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/?demo=1   — все коробочки открыты
```

С параметром `?demo=1` (или `demo: true` в конфиге) коробочки открыты без ожидания и появляется кнопка «Сбросить прогресс».

## Подключение к Telegram

1. **Разместите папку на хостинге с HTTPS.** Варианты:
   - GitHub Pages: залейте файлы в репозиторий, затем Settings → Pages → Deploy from branch;
   - Vercel / Netlify: перетащите папку в веб-интерфейс.
2. **Создайте бота** у [@BotFather](https://t.me/BotFather): `/newbot`.
3. **Кнопка в меню бота:** `/mybots` → ваш бот → Bot Settings → Menu Button → вставьте URL сайта.
4. **(По желанию) прямая ссылка на мини-апп:** `/newapp` → выберите бота → URL → короткое имя.
   Ссылка получится вида `https://t.me/<bot>/<appname>`. Демо-режим включается так: `https://t.me/<bot>/<appname>?startapp=demo`.

Сервер для бота не нужен: всё работает через кнопку меню.

## Что уже сделано под Telegram

- `Telegram.WebApp.ready()` / `expand()`, цвет шапки под фон;
- виброотклик (HapticFeedback) при открытии, на закрытых коробочках и при встряхивании шара;
- системная кнопка «Назад» закрывает открытую коробочку;
- прогресс хранится в **Telegram CloudStorage**, поэтому синхронизируется между устройствами пользователя.
  Вне Telegram используется localStorage.

## Важно

- Дата считается **по часам устройства** пользователя. Для подарочного адвента этого достаточно, но
  кто захочет, сможет перевести время и открыть коробочку раньше. Если это критично, нужна проверка на сервере.
- Музыка запускается только после нажатия на кассету: так требуют браузеры и Telegram.
- Шрифты Playfair Display, Marck Script и Manrope подгружаются из Google Fonts. Если они не загрузятся, будут системные.

## Заставка-коробочка

При каждом запуске календарь появляется из розовой коробочки с бантом: по нажатию бант развязывается,
крышка улетает, а календарь «вылетает» изнутри. Если не нажимать, коробочка откроется сама через 6 секунд.
Надписи на этикетке и время автооткрытия задаются в `intro` в `js/config.js`.

## Общая ёлка

Под календарём стоит ёлка. Каждый пользователь выбирает игрушку из 10 шаблонов и вешает её на ветку
(максимум 3 игрушки на человека). Нажатие на чужую игрушку показывает, кто её повесил.

Чтобы игрушки видели **все**, нужна база данных. Сайт на GitHub Pages статический, поэтому используется
бесплатная Firebase Realtime Database (подключается через REST, без SDK):

1. Зайдите на <https://console.firebase.google.com>, создайте проект (Google Analytics можно выключить).
2. Build → **Realtime Database** → Create database → регион (например, Belgium) → **Start in locked mode**.
3. На вкладке **Rules** вставьте правила ниже и нажмите Publish.
4. Скопируйте адрес базы сверху на вкладке Data (вида `https://xxx-default-rtdb.europe-west1.firebasedatabase.app`)
   и вставьте в `js/config.js` → `tree.firebaseUrl`.

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "ornaments": {
      ".read": true,
      "$uid": {
        "$slot": {
          ".write": "!data.exists() && $slot.matches(/^[012]$/)",
          ".validate": "newData.hasChildren(['t', 'x', 'y']) && newData.child('t').isNumber() && newData.child('t').val() >= 0 && newData.child('t').val() <= 9 && newData.child('x').isNumber() && newData.child('y').isNumber() && (!newData.child('n').exists() || (newData.child('n').isString() && newData.child('n').val().length <= 40))"
        }
      }
    }
  }
}
```

Правила разрешают каждому пользователю только 3 места (`0`, `1`, `2`) и не дают перезаписать или удалить уже
висящую игрушку. Пользователь определяется по Telegram ID. Проверки подписи Telegram на сервере нет, поэтому
при желании лимит можно обойти, но для праздничной ёлки этого достаточно.

Пока `firebaseUrl` пустой, ёлка работает локально: игрушки видны только на этом устройстве.
Новые игрушки других людей подгружаются раз в 20 секунд.
