# Сервер бота: `/start` и `!инфа @ник`

Бот адвента получает небольшой сервер на Cloudflare Workers (бесплатно). Мини-апп при этом работает как раньше.

- `/start` — приветствие и кнопка «🎄 Открыть адвент».
- `!инфа @ник` (или `/info @ник`) — карточка участника Информа из Google Таблицы: сообщение с кликабельными
  Telegram и Instagram, почтой и кнопкой «🪪 Открыть карточку», которая открывает HTML-страницу карточки.
  Искать можно по Telegram-нику, ссылке `t.me/…`, Instagram-нику, нику («Молоко») или фамилии.

**Кто может пользоваться:** только в личке с ботом, только люди, чей Telegram-ник есть в таблице
(и у кого не заполнена «Дата ухода»), плюс Telegram ID из `ADMIN_IDS`. В группах бот на `!инфа` молчит.
Страница карточки проверяет подпись Telegram (`initData`), поэтому по прямой ссылке её не открыть.

**Где данные:** только в вашей Google Таблице. В репозиторий и на GitHub Pages они не попадают.

## 1. Таблица

Первая строка — заголовки. Бот понимает такие (регистр не важен, лишние столбцы игнорируются):

| Ник | Роль | Фамилия | Имя | Отчество | Дата рождения | Знак зодиака | Группа | Форма обучения | Телефон | Почта | Инстаграм | Телеграм | Размер | Метро | Дата вступления | Дата ухода | Фото |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

- «Телеграм» — ник с `@` или без, можно ссылкой `t.me/…`. По нему бот ищет и проверяет доступ.
- «Знак зодиака» можно не заполнять — посчитается из даты рождения.
- «Фото» — необязательная ссылка на картинку для аватарки. Пусто — будет первая буква ника.
- Пустые ячейки и `-` показываются прочерком.

## 2. Apps Script (чтение закрытой таблицы)

1. В таблице: **Расширения → Apps Script**, вставьте код из `apps-script.gs`, сохраните.
2. **Настройки проекта** (шестерёнка) → **Свойства скрипта** → добавьте `KEY` = длинная случайная строка.
3. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**,
   «Запуск от имени»: **я**, «У кого есть доступ»: **все** → **Начать развертывание**, разрешите доступ.
4. Скопируйте URL веб-приложения (заканчивается на `/exec`).

«Доступ: все» означает, что адрес отвечает без входа в Google, но без правильного `KEY` отдаёт только `{"error":"forbidden"}`.

## 3. Cloudflare Worker

1. Зарегистрируйтесь на <https://dash.cloudflare.com> → **Workers & Pages → Create → Create Worker** →
   имя, например `advent-bot` → **Deploy**.
2. **Edit code** → удалите шаблон, вставьте весь `worker.js` → **Deploy**.
3. **Settings → Variables and Secrets** → добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен бота из BotFather |
   | `WEBHOOK_SECRET` | Secret | длинная случайная строка (латиница и цифры) |
   | `SHEET_URL` | Text | URL Apps Script (`…/exec`) |
   | `SHEET_KEY` | Secret | тот же `KEY`, что в Apps Script |
   | `ADMIN_IDS` | Text | ваш Telegram ID (узнать у @userinfobot), можно несколько через запятую |
   | `ADVENT_URL` | Text | `https://piccologatto01.github.io/nice_advent/` |

4. Откройте в браузере `https://advent-bot.<ваш-аккаунт>.workers.dev/setup?key=<WEBHOOK_SECRET>`.
   Должно вернуться `{"ok":true,"result":true,"description":"Webhook was set"}`.

Готово: напишите боту `/start`, затем `!инфа @ник`.

## Полезно знать

- Изменения в таблице подхватываются в течение 5 минут (бот кэширует таблицу).
- Сообщение-карточка приходит через Telegram, поэтому работает всегда. Кнопка «Открыть карточку» открывает
  страницу на `workers.dev`; если у кого-то она не грузится без VPN, все данные всё равно есть в сообщении.
- В HTML-карточке нажатие на Telegram/Instagram открывает профиль, на почту или телефон — копирует их
  и открывает почтовое приложение / звонилку.
- Если сменить токен бота — обновите `BOT_TOKEN` и снова откройте `/setup?key=…`.
