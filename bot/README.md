# Бот: `/start` и `!инфа @ник` (всё в Google Таблице)

Бот работает на **Google Apps Script** прямо внутри таблицы с анкетами Информа: ни серверов, ни Cloudflare,
только твой Google-аккаунт. Мини-апп адвента при этом работает как раньше.

- `/start` — приветствие и кнопка «🎄 Открыть адвент».
- `!инфа @ник` (или `/info @ник`) — карточка участника: сообщение с кликабельными Telegram и Instagram
  и кнопка «🪪 Открыть карточку» — HTML-страница в стиле анкеты (`card.html` на GitHub Pages).
  Искать можно по Telegram-нику, ссылке `t.me/…`, Instagram-нику, нику («Молоко») или фамилии.

**Кто может пользоваться:** только в личке с ботом и только люди, чей Telegram-ник есть в таблице
(без «Даты ухода»), плюс Telegram ID из `ADMIN_IDS`. В группах бот на `!инфа` молчит.
Страница карточки проверяет подпись Telegram, по пересланной ссылке её не открыть.
Данные лежат только в таблице: в репозиторий и на GitHub Pages они не попадают.

## 1. Таблица

Первая строка — заголовки (регистр не важен, лишние столбцы можно оставить):

`Ник · Роль · Фамилия · Имя · Отчество · Дата рождения · Знак зодиака · Группа · Форма обучения · Телефон · Почта · Инстаграм · Телеграм · Размер · Метро · Дата вступления · Дата ухода · Фото`

- «Телеграм» — ник с `@` или без (по нему бот ищет и даёт доступ).
- «Знак зодиака» можно не заполнять — посчитается из даты рождения.
- «Фото» необязательно: без него бот возьмёт аватарку из публичного профиля Telegram.

## 2. Скрипт

1. В таблице: **Расширения → Apps Script**. Удали всё в редакторе и вставь код из `telegram-bot.gs`. Сохрани (💾).
2. **Настройки проекта** (шестерёнка слева) → внизу **Свойства скрипта → Добавить свойство**:
   - `BOT_TOKEN` — токен из @BotFather;
   - `ADMIN_IDS` — твой Telegram ID (узнать у @userinfobot), можно несколько через запятую.
3. Вверху справа **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**:
   «Запуск от имени»: **Я**, «У кого есть доступ»: **Все** → **Начать развертывание** →
   разреши доступ (Google предупредит, что приложение не проверено: «Дополнительные настройки → Перейти»).
4. Скопируй **URL веб-приложения** (оканчивается на `/exec`) и добавь его в свойства скрипта как `WEBAPP_URL`.
5. Вернись в редактор, вверху выбери функцию **setup** и нажми **Выполнить**.
   В журнале должно появиться `Webhook: {"ok":true,…}`, имя бота и число участников.

Готово: напиши боту `/start`, потом `!инфа @ник`.

## Если меняешь код

После правок в коде: **Начать развертывание → Управление развертываниями** → карандаш →
«Версия»: **Новая версия** → **Развернуть**. Адрес `/exec` при этом не меняется, `setup` запускать не нужно.

## Полезно знать

- Изменения в таблице подхватываются в течение 5 минут.
- Если сменил токен бота — обнови `BOT_TOKEN` и снова запусти `setup`.
- Сообщение-карточка приходит через Telegram и работает всегда. Кнопка «Открыть карточку» открывает
  GitHub Pages; если у кого-то страница не грузится без VPN, все данные всё равно есть в сообщении.
- Бесплатные лимиты Google Apps Script (десятки тысяч запросов в день) для такого бота с запасом.
